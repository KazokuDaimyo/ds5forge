# Brand logos

The overlay and the controller menu show the two modes with the logos of what they present to the games:

| File | Used for |
|---|---|
| `xbox.svg` | Xbox 360 mode (the virtual controller) |
| `playstation.svg` | Native mode (the real DualSense) |

The logos are drawn in the text colour whatever colour the files were saved in (see `src/brand.ts`).

## Where they come from

- `xbox.svg`: <https://www.svgrepo.com/svg/520367/xbox>
- `playstation.svg`: <https://www.svgrepo.com/svg/473754/playstation>

To replace one, save the new file under the same name.
